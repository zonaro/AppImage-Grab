Seu fluxo de AppImages merece ser simples.

O AppImage Grab automatiza o caminho do download até o gerenciador que você já usa.

Baixou, integrou.

Com ON, o AppImage Grab identifica o download concluído e o envia ao Gear Lever ou Shelly. Uma notificação informa o resultado.

.AppImage→Gear Lever / Shelly

Escolha o seu gerenciador.

Você decide quando.

COMECE AGORA

Um comando para começar.

Linux, Python 3.10+, Git, curl e pelo menos um gerenciador instalado: Gear Lever ou Shelly. Rode o comando para preparar a extensão e a integração local.

Terminal · bashLinux
$curl -fsSL https://raw.githubusercontent.com/zonaro/AppImage-Grab/main/install.sh | bash

Confira o script no GitHub antes de executá-lo. A instalação da extensão no navegador exige confirmação manual.

SEM LETRAS MIÚDAS

As dúvidas antes do primeiro download.

A ideia é simples. E as limitações também precisam ficar claras.

Pergunte ou reporte no GitHub ↗
Preciso instalar Gear Lever e Shelly?

Não. Basta um dos dois. Escolha Gear Lever ou Shelly no popup; suas bibliotecas continuam separadas, sem migração automática.

Como funcionam as atualizações?

Cada gerenciador cuida das atualizações. O Gear Lever permite ações individuais; no Shelly, a CLI disponível atualiza todas as AppImages com atualização de uma vez, mediante confirmação.

Posso desligar a automação?

Sim. O toggle OFF desativa novas integrações automáticas sem interromper nem modificar os downloads do navegador.

Por que preciso autorizar a extensão manualmente?

Os navegadores exigem autorização para extensões carregadas localmente. O instalador prepara os arquivos e registra o host, mas não contorna essas proteções.

O download é seguro por padrão?

O Grab não executa AppImages nem inspeciona seu formato. Ele verifica apenas o caminho recebido pelo serviço local e entrega o arquivo ao gerenciador escolhido. Baixe arquivos somente de fontes confiáveis.
