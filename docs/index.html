Seu fluxo de AppImages merece ser simples.

O Grab resolve a parte repetitiva. O Gear Lever continua fazendo o trabalho que já faz bem.

Baixou, integrou.

Quando está ON, o Grab detecta o fim de um download AppImage e o envia ao Gear Lever. Sem arrastar arquivo de uma janela para outra.

.AppImage→Gear Lever

Updates no caminho certo.

Reconhece links de releases GitHub, GitLab e Codeberg e registra a fonte no Gear Lever quando possível. Sem adivinhar repositórios.

Você decide quando.

Um toggle ON/OFF no navegador liga ou desliga a integração. Com OFF, seus downloads continuam exatamente como antes.

Aproveita o Gear Lever.

Nada de substituir o gerenciador. A integração utiliza a CLI existente e respeita as configurações de pasta e movimentação do Gear Lever.

COMECE AGORA

Um comando para começar.

Linux, Gear Lever instalado, Python 3.10+, Git e curl. Cole o comando abaixo no terminal para instalar o serviço local e preparar a extensão.

Terminal · bashLinux
$curl -fsSL https://raw.githubusercontent.com/zonaro/gear-lever-grab/main/install.sh | bash

Confira o script no GitHub antes de executá-lo. A instalação da extensão no navegador exige confirmação manual.

SEM LETRAS MIÚDAS

As dúvidas antes do primeiro download.

A ideia é simples. E as limitações também precisam ficar claras.

Pergunte ou reporte no GitHub ↗
Preciso ter o Gear Lever instalado?

Sim. O Grab é uma ponte para o Gear Lever, não um substituto. Ele usa a CLI do aplicativo para integrar AppImages e configurar fontes de atualização.

Ele atualiza todos os AppImages sozinho?

Não. O Grab registra fontes de atualização quando reconhece a origem; o Gear Lever continua responsável por verificar e aplicar updates. Nem todo download permite identificar uma fonte confiável.

Posso desligar a automação?

Sim. O toggle OFF desativa novas integrações automáticas sem interromper nem modificar os downloads do navegador.

Por que preciso autorizar a extensão manualmente?

Os navegadores exigem autorização para extensões carregadas localmente. O instalador prepara os arquivos e registra o host, mas não contorna essas proteções.

O download é seguro por padrão?

O Grab valida formato e caminho, não executa a AppImage diretamente e só processa downloads HTTPS. Isso não comprova a autenticidade do aplicativo: baixe apenas de fontes confiáveis. O Gear Lever pode ler metadados durante a integração.
