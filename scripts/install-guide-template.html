INSTALAÇÃO MANUAL NO NAVEGADOR

Seu AppImage Grab está preparado.

O serviço Python já está instalado. Falta carregar a extensão descompactada no seu navegador. Leva poucos cliques e não exige instalar nenhum pacote.

Versão instalada (commit da main):

1. Escolha seu navegador

Detectamos estes navegadores neste computador. Escolha em qual deseja adicionar a extensão.

O instalador tenta abrir esta página diretamente no navegador padrão. Para outro navegador ou se ela não abriu, copie o endereço e cole na barra.

2. Copie o caminho exato

Este é o local real da extensão instalada no seu computador. No Chromium selecione a pasta; no Firefox, o arquivo manifest.json.

No seletor de arquivos, você pode usar Ctrl+L para colar o caminho, quando disponível.

3. Carregue a extensão

    Pronto para usar

    Depois de carregar a extensão, abra seu popup e ative o toggle ON somente se desejar integrar downloads automaticamente. O gerenciador selecionado, Gear Lever ou Shelly, continua responsável pelos aplicativos e atualizações.

    Para atualizar o AppImage Grab depois, rode o mesmo install.sh e recarregue a extensão pelo gerenciador do navegador. O controle ON/OFF permanece independente.

    Este guia é um arquivo HTML local: não instala nada no navegador, não altera configurações e não transmite dados. Os botões apenas abrem ou copiam endereços.
